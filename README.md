# STUDY BRITAIN – Interactive Educational Learning Platform

A modern, interactive educational website built with **100% fidelity** to the authoritative curriculum textbook: **"PART I: THE COUNTRY OF BRITAIN"**.

---

## 🌟 Key Features

### 1. Dual Complementary Learning Modes
- **Visual Learning Mode:** Richly organized with interactive diagrams, collapsible accordion sections, historical timelines, comparison cards, and inline check quizzes.
- **Full Content Mode:** Preserves 100% of the verbatim document text, headings, bullet points, nested points, tables, numbers, dates, examples, and conclusions, equipped with a sticky Table of Contents and reading progress bar.

### 2. Interactive Visual Components
- **British Isles vs UK Diagram:** Interactive SVG visualizer separating geographical entities (British Isles ~315,159 km², population ~72M; Great Britain 229,850 km²) from sovereign states (UK, Republic of Ireland).
- **The Four Nations Explorer:** England (London), Scotland (Edinburgh), Wales (Cardiff), and Ireland / Northern Ireland, highlighting language families, the dominance of England, and sporting loyalties.
- **Union Jack Historical Timeline:** Interactive progression through **1194**, **1606**, and **1801**, complete with SVG flag components and the historical explanation of the Welsh dragon's absence.
- **Attitudes Concept Flow Map:** Visualizing the relationship between Multiculturalism, Individualism, and Conservatism & Being Different.
- **Side-by-Side Comparison Cards:** Direct contrasts of Traditional Stereotypes vs Modern Reality, Public Formality vs Private Informality, Individualism vs The Talented Amateur, and Sex Openness vs Privacy Protection.

### 3. Examination & Practice System
- **Question Types:** Multiple-choice, True/False, Fill-in-the-blank, Matching exercises, and Chronological ordering.
- **Quiz Sets:** Section Quick Checks, Chapter 1 Comprehensive Quiz, Chapter 2 Comprehensive Quiz, and the Cumulative Part I Final Exam.
- **Features:** Instant feedback with exact source references, detailed explanations, score calculation, confetti celebrations, and a "Retry Missed Questions" mode.

### 4. Interactive 3D Flashcards & Vocabulary Center
- **Flashcard Deck:** 3D flip card animation, category filtering, shuffle, mastery tracking (Known vs Need Review).
- **Vocabulary Center:** Verbatim definitions, original Vietnamese translations from the source (e.g. *Stereotype: Định kiến / khuôn mẫu*, *Artificial preservation: Sự bảo tồn mang tính nhân tạo*), and British English speech synthesis.

### 5. Review Center & Global Search
- **Review Center:** Automatically logs quiz errors, flashcards requiring review, and incomplete lessons with persistent storage in LocalStorage.
- **Global Search (`Ctrl+K`):** Instant search across all dates (1194, 1603, 1606, 1800, 1801, 1922, 1993, 1994), vocabulary, section titles, and text contents.
- **100% Content Audit Modal:** Verifies item-by-item completeness against the textbook.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Running Locally

```bash
# Start the development server
npm run dev

# Or build for production and preview
npm run build
npm run preview
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
